Fake operator for automated tests

Forge outcome: hardened. Handed to the spec through forged-idea.md, after AD-9 is corrected.

Locked decisions

  • The contract is the scaleway-operator code, not AD-9 as written. AD-9 is corrected before the spec.
  • All outcomes from the start, per kind, only where the real operator produces them.
  • The annotation carries the Scaleway-side cause (NotFound, Error, Locked, Revoked). The fake writes the kind's effect. A cause a kind does not support gives a visible Error.
  • State model with no memory: a cause applies while the annotation is present. source-version: n simulates a new secret version.
  • Preconditions are checked on the real cluster state: the project-id annotation and the NamespaceRole. On failure: Error and no finalizer.
  • The steps follow the real operator's order. The delay between steps is configurable, default 2 s. Polling, no watch.
  • internal/kube reads no token. The fake passes its own ServiceAccount token. Its RBAC never touches Secrets.
  • A separate Dockerfile, a local image that is never pushed, raw manifests in tests/cluster/fake-operator/, and a guard test that keeps it out of the release.
  • kubetest mimics the API server: merge patch, the /status subresource, deletion with finalizers, resourceVersion and 409, 401.

Weak points found in the existing material

  • AD-9 forces Pending and TerminationBlocked on every kind. In the operator they exist only for LoadBalancer. For an Instance, a Scaleway 404 gives Syncing.
  • AD-9 omits Revoked, FinalizerRemovedWithoutScalewayDelete, and the precondition errors that leave an object without a finalizer.
  • A fake with no consumer drifts. It is mitigated by copying the operator's code instead of inventing behavior.
  • With no access to Secrets, last_synced_resource_version is never written, and a real source-Secret change cannot be observed.

Rejected, and why

  • Nominal cycle only: the coherence review would flag it against AD-9 and force a second round.
  • AD-9 to the letter: tests would mimic behavior the real operator never has.
  • Effect values in the annotation: every scenario would need the per-kind table.
  • Releasing Syncing by annotation instead of a delay; a watch in #42; internal/kube reading a ServiceAccount token (AD-3).
  • Access to Secrets; a third FROM in the release Dockerfile; an event model for causes; a NewVersion cause.
