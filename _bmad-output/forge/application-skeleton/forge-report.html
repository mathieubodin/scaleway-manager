Application skeleton

Go binary, Dockerfile, minimal chart. Issue #41, forge session for Mathieu.

Handoff: forged-idea.md → bmad-spec via sdlc-work.

Locked decisions

  • #41 ships the minimum executable verification: make targets (go vet + go test, helm lint + template, docker build), a CI job, and the AD-1 require check. Coverage, mutation, thresholds stay in #14.
  • Two ClusterRoles without rules, unbound: scaleway-manager-namespace, scaleway-manager-cluster.
  • HTTPRoute: one rule on /; Gateway name and namespace required; sectionName and hostnames optional.
  • Server: LISTEN_ADDR (default :8080), /healthz → 200 ok, static placeholder page, AD-8 headers on every response, 10 s graceful shutdown, slog JSON.
  • Image built locally for the host architecture, unsigned; chart version 0.0.0.
  • Restricted securityContext, drop: [ALL] with no capability added; dedicated ServiceAccount without token or binding.

Rejected, and why

  • Credentials Role now: scaleway-system exists only after the real operator's install; the test cluster would fail.
  • Default Gateway: a route attached to no listener fails silently.
  • /api/events rule now: the stream does not exist yet.
  • NET_BIND_SERVICE: not needed for port 8080; the Service maps 80 → 8080 outside the pod (challenged by Mathieu, kept).
  • Make targets without CI: Go code would merge unchecked.

Weak points that survived

  • crack prek check-yaml rejects Helm templates: exclude charts/*/templates/.
  • crack pr-checks.yml has no Go job today.
  • accepted A port below 1024 in LISTEN_ADDR is only documented, not rejected.
